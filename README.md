# Bitmasker

An Unreal Engine plugin for manipulating bitmasks.

## Install

If your project is on Git, the recommended setup is to simply [submodule](https://git-scm.com/book/en/v2/Git-Tools-Submodules) this repository in your `Plugins` folder.
